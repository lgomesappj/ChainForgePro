## Installation

1. Clone the repository: `git clone https://github.com/harutosati/ChainForgePro.git`
2. `cd ChainForgePro`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainForgePro is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
